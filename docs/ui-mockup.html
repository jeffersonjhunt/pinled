Versions

A version pairs the install config with the machine profile, because what you are comparing is a look — and a look spans both. Applying one is an ordinary write; the board reports whether it had to re-initialise.

!
Versions live here in the app — in your private library, or as files on disk if you would rather not use the cloud. The board keeps one active configuration and no history: only one can be in effect, so copies on the device would be dead weight and a second thing to keep in step.

Firmware

The board never contacts the internet. This app checks the version, fetches the image, and hands it over on your local network — so an update works the same whether the machine is online or not.

Update

  1. Image downloaded
    Fetched and checksum verified in the browser.
  2. Arm the board
    Press the button on the device. Physical presence is the whole authorisation — there is no password to lose.
  3. Send
    Uploads over your local network to the spare slot.
  4. Restart
    Boots the new slot. The old one stays intact.
