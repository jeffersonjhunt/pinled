Install

How this particular build is wired. Private to you — it describes one physical machine, so it is never published, though you can export it and restore it onto a replacement board.

!
Wi-Fi credentials are not part of this document and appear in no export, at any privacy level (FR-CFG-12). Restoring a backup onto a new board therefore starts with provisioning — which is correct, since the network is usually different too.

Versions

A version pairs the install config with the machine profile, because what you are comparing is a look — and a look spans both. These are plain JSON files on your disk; the board keeps one active configuration and no history.

Profiler

Colour lab

Pin one LED to exact bytes, live — no apply, no restart. Sweep gamma until the LED matches the swatch (1.00 = raw bytes; the runtime default is 2.20), and judge hue at a moderate level — a bare LED at full power blooms the eye toward white no matter what the bytes say. The gamma that wins here goes into the install config as render.gammaX100.
